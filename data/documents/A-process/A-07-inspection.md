# A-07. 검사 절차 (Inspection Procedures)

## 검사의 목적

블렌딩 후 디젤 제품이 KS M 2610(국내) 또는 고객 사양을 충족하는지 확인하는 마지막 관문. 출하 결정의 근거가 된다.

## 주요 검사 항목과 측정 방법

### 1. CFPP (Cold Filter Plugging Point, 한외여과점)

| 항목 | 내용 |
| --- | --- |
| 측정 표준 | ASTM D6371 / EN 116 |
| 원리 | 시료를 1°C씩 냉각하면서 표준 필터(45μm)를 20초 내에 통과하지 못하는 온도 |
| 측정 시간 | 약 30~60분 (시료 온도에 따라 달라짐) |
| 측정 정밀도 | ±1°C 수준 |
| 한국 규격 | 동절기(11~3월) -16°C 이하, 일반 -5°C |

### 2. CP (Cloud Point, 운점)

| 항목 | 내용 |
| --- | --- |
| 측정 표준 | ASTM D2500 / D5773 |
| 원리 | 시료가 냉각되며 처음으로 흐려지는 (왁스 결정 발생) 온도 |
| 일반 관계 | CP = CFPP + 2~5°C |

### 3. PP (Pour Point, 유동점)

| 항목 | 내용 |
| --- | --- |
| 측정 표준 | ASTM D97 / D5949 |
| 원리 | 시료가 냉각되며 더 이상 흐르지 않게 되는 온도 |
| 일반 관계 | PP = CFPP + 5~9°C |

### 4. 기타 주요 검사

| 검사 | 표준 | 한국 KS 사양 |
| --- | --- | --- |
| 황분 (Sulfur) | ASTM D5453 | ≤ 10 ppm |
| 세탄 지수 | ASTM D4737 | ≥ 52 |
| 밀도 (15°C) | ASTM D4052 | 815~845 kg/m³ |
| 인화점 (Flash Point) | ASTM D93 | ≥ 40°C |
| 증류성상 (T95) | ASTM D86 | ≤ 360°C |
| 색상 | ASTM D1500 | ≤ 2.5 |

## 샘플링 절차

1. 블렌드 탱크 충분 교반 후 30분 정치
2. 상·중·하 3점에서 시료 채취 (또는 자동 샘플러 사용)
3. 시료 균질화
4. 우선 CFPP, CP, 황분 측정 (보통 1시간 이내 완료)
5. 추가 검사 항목은 병행 (밀도, 세탄 등)

## 검사값 신뢰도 이슈

검사값이 정확해 보여도 다음 상황에서 **신뢰도 의심** (`inspection_reliability` reason code):
- 시료 채취 직후 변동 (정치 부족)
- 측정 장비 노후·캘리브레이션 미흡
- 동일 시료 재측정 시 1°C 이상 차이
- 다른 측정 항목과 모순 (예: CFPP는 통과지만 PP가 너무 낮음)

## 재검사 결정 기준

베테랑 연구원의 일반적 재검사(retest) 결정:
- 측정값이 사양 경계에서 ±0.5°C 이내
- 동일 배치 내 변동이 1°C 초과
- 직전 배치와의 변동이 평소 패턴 벗어남
