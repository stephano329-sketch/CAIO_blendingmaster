# A-02. HDS (Hydrodesulfurization, 수소화 탈황)

## 공정 목적

HDS는 디젤 유분에 포함된 황(Sulfur)을 제거하여 환경 규제(한국 KS M 2610: 황 함량 10ppm 이하)를 만족시키는 공정이다. CDU에서 나온 LGO는 황 함량이 보통 1,000~10,000ppm 수준이므로, 1~3차 HDS를 거쳐 ULSD(Ultra-Low Sulfur Diesel) 사양으로 가공된다.

## 운전 원리

LGO를 수소(H₂)와 함께 촉매층에 통과시키면, 황이 황화수소(H₂S)로 전환되어 분리된다. 주반응:

```
R-S-R' + 2H₂ → R-H + R'-H + H₂S
(조합된 황 화합물)            (탄화수소)  (황화수소)
```

생성된 H₂S는 후단의 Amine Treating 또는 Claus 공정에서 회수·처리된다.

## 운전 조건

| 항목 | 일반 운전 범위 |
| --- | --- |
| 반응 온도 | 320~380°C |
| 반응 압력 | 50~70 bar |
| 수소/원료 비 (H₂/Oil) | 200~400 Nm³/m³ |
| 공간속도 (LHSV) | 1~3 hr⁻¹ |
| 촉매 | CoMo/NiMo on Al₂O₃ |

## 디젤 품질에 미치는 영향

- **세탄 지수**: 일반적으로 HDS 후 약간 상승 (수소화로 방향족이 일부 포화)
- **밀도**: 약간 감소 (수소화로 가벼워짐)
- **CFPP**: 변화 적음, 다만 강한 수소화 처리 시 미량의 n-파라핀 이성질화로 약간 개선될 수 있음
- **색상·안정성**: 매우 개선 (불포화·황 화합물 제거)

## 운전 조건 변화의 위험

- **온도 과도 상승**: 수소 소비 ↑, 촉매 노화 가속, 연료비 ↑
- **수소 압력 부족**: 황 제거율 저하 → Off-spec 위험
- **촉매 노후**: 활성 저하로 황 함량 상승 → 마지막 출하 검사에서 적발될 위험

## 베테랑 점검 포인트

검사값에서 황분이 5ppm을 넘기 시작하면 촉매 사이클 후반이거나 운전 조건 이상을 의심한다. 황분 변동성은 곧 CFPP 측정 신뢰도에도 영향을 줄 수 있으므로 동시에 확인한다.
