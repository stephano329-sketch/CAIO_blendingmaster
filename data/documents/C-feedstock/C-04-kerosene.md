# C-04. Kerosene (등유) — 디젤 블렌딩 보조

## 정의와 위치

Kerosene(등유)는 비점 180~250°C 구간으로, 일반적으로 **항공유(Jet Fuel)**나 **등유 제품(난방유)**으로 판매된다. 디젤 블렌딩에는 **저온유동성 강화 목적**으로 제한적으로 사용된다.

## 디젤 블렌딩 시 사용 사례

Kerosene을 디젤에 혼합하는 것은 **자주는 아니지만** 다음 상황에서 활용된다:

1. **혹한기 CFPP 강화**: WAFI만으로 도달 불가능한 매우 낮은 CFPP 목표 시
2. **신규 원유 슬레이트 적응 기간**: LGO 성상이 흔들릴 때 안정 보강
3. **재블렌딩 시 보정**: CFPP 미달이 큰 경우 빠른 보정

## 주요 성상

| 항목 | 일반 범위 | 평균 |
| --- | --- | --- |
| 비점 (T50) | 200~230°C | 215°C |
| 밀도 (15°C) | 785~810 kg/m³ | 795 kg/m³ |
| 황분 | 5~10 ppm | 7 ppm |
| 세탄 지수 | 45~55 | 50 |
| **CFPP** | **-50 ~ -30°C** | **-40°C** |
| 인화점 | 38~50°C | 42°C |
| n-파라핀 C10~C15 | 15~25 wt% | 20 wt% |
| n-파라핀 C16~C20 | 1~3 wt% | 2 wt% |
| n-파라핀 C21+ | 0~0.5 wt% | 0 wt% |
| 방향족 | 15~22 vol% | 18 vol% |

→ 본 시스템 `physical_model.py`의 Kerosene baseline CFPP = -40°C와 정합

## 디젤 블렌딩 시 영향

### 긍정적
- **CFPP 대폭 개선**: 자체 CFPP -40°C로 매우 우수
- **세탄 유지**: 등유 세탄 50+ 으로 풀 세탄에 큰 영향 없음
- **밀도 조정**: 풀 밀도가 너무 무거울 때 가벼워짐
- **저온 유동성**: 동절기 출하·저장 안정성 ↑

### 부정적
- **인화점 저하**: 등유 인화점 38~50°C → 디젤 풀 인화점이 KS 사양 40°C 하한에 가까워짐 위험
- **점도 저하**: 동점도 사양(1.9~5.5 mm²/s) 하한 위협
- **윤활성 부족**: 등유 자체 윤활성 약함 → 윤활성 향상제 보강 필요
- **수율 손실**: 등유로도 팔 수 있는 제품을 디젤로 돌리는 경제성 고려

## 운영 비율

| 시즌 | 일반 Kero 비중 |
| --- | --- |
| 하절기 | 0% (불필요) |
| 동절기 | 0~5% |
| 혹한기 | 5~10% |

본 시스템은 `kero_ratio` 범위를 **0~0.10 (0~10%)**로 제한한다 — 한국 정유사 일반 운영 범위.

## CFPP 영향 정량 (예시)

LGO 75% + HGO 0% + LCO 5% + Kero 10% + Bio 3% + WAFI 미투입:
```
CFPP_base = 0.75 × (-6) + 0 + 0.05 × (-6) + 0.10 × (-40) + 0.03 × 5
          = -4.5 + 0 - 0.3 - 4.0 + 0.15
          = -8.65°C
```

같은 블렌드에서 Kero 10%를 LGO로 대체하면:
```
CFPP_base = 0.85 × (-6) + 0 + 0.05 × (-6) + 0 + 0.03 × 5
          = -5.1 + 0 - 0.3 + 0 + 0.15
          = -5.25°C
```

→ Kero 10% 사용으로 약 **3.4°C 추가 개선** 효과.

## 베테랑 점검 포인트

### 1. 인화점 검사 강화
Kero 사용 케이스에서는 인화점 사양 40°C 하한을 면밀히 확인. 제품 인화점이 41~42°C로 측정되면 안전 마진 부족 신호.

### 2. 점도·윤활성 검사
점도 1.9 mm²/s 하한, HFRR 460μm 상한 확인.

### 3. 등유 풀 운영과의 균형
등유로 팔 수 있는 분량을 디젤로 돌릴 때 경제성·재고 균형 검토.

### 4. 신규 등유 lot 도입 시
등유 lot마다 성상 미세 변동 가능 → 첫 1~2 배치 모니터링.
