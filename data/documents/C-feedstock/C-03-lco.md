# C-03. LCO (Light Cycle Oil) — 경질 사이클 오일

## 정의와 위치

LCO(Light Cycle Oil)는 **FCC 부산물**로, 비점 220~360°C 구간에서 생성된다. 가솔린이 주 목적인 FCC에서 부산물로 나오기 때문에 양은 안정적이지만, 디젤 블렌딩 시 **신중한 취급**이 필요하다.

## 생산 메커니즘

FCC에서 중질 유분(VGO)이 고온·촉매 분해되면:
- 가솔린 (목표 제품)
- LCO (부산물, 220~360°C)
- HCO (Heavy Cycle Oil, 360°C+)
- 코크 (촉매 표면 침적)

LCO는 FCC 분해의 자연스러운 부산물로, FCC 운전이 정상이면 안정적으로 공급된다.

## 주요 성상 범위 (HDS 처리 후)

| 항목 | 일반 범위 | 평균 |
| --- | --- | --- |
| 비점 (T50) | 270~310°C | 290°C |
| 밀도 (15°C) | 880~920 kg/m³ | 895 kg/m³ |
| 황분 | 5~15 ppm | 9 ppm |
| **세탄 지수** | **20~35** | **30** |
| **CFPP** | **-10 ~ -2°C** | **-6°C** |
| n-파라핀 C10~C15 | 1~5 wt% | 3 wt% |
| n-파라핀 C16~C20 | 3~8 wt% | 5 wt% |
| n-파라핀 C21+ | 1~2 wt% | 1.5 wt% |
| **방향족** | **45~70 vol%** | **55 vol%** |
| 색상 | 진한 갈색 | — |

→ 본 시스템 `physical_model.py`의 LCO baseline CFPP = -6°C와 정합

## LCO의 핵심 특징: 방향족 高함량

LCO는 **방향족 함량이 매우 높다 (45~70%)**. 이는 다음 영향을 미친다:

### 1. 세탄 지수가 매우 낮음
- 방향족은 세탄 지수가 낮은 화합물군
- LCO 자체 세탄 30 → 디젤 풀 평균 세탄 끌어내림
- 디젤 풀에서 LCO 12% 이상 사용 시 세탄 미달 위험

### 2. WAFI 효과 감쇠
방향족이 WAFI 첨가제와 간섭하여 효과를 약화시킨다. 본 시스템 모델링:
- `LCO 비율 > 15%` → WAFI 효과 30% 감쇠
- 동일 ppm으로 같은 ΔCFPP를 얻으려면 약 1.4배 더 투입 필요

### 3. 색상·안정성 이슈
- 방향족과 일부 잔류 올레핀이 산화·중합 가능성
- 장기 저장 시 슬러지 형성 위험
- 수출용 디젤은 색상 사양 엄격하므로 LCO 비중 더 낮춤

### 4. 밀도 高
- 880~920 kg/m³로 디젤 풀에서 가장 무거움
- 디젤 규격 밀도 상한(845) 부근에서 운영 시 LCO 비중 제한

## 일반 운영 비율

| 시즌 | 일반 LCO 비중 |
| --- | --- |
| 하절기 | 8~12% (CFPP 부담 적어 활용) |
| 동절기 | 5~8% (CFPP 부담으로 줄임) |
| 혹한기 | 3~5% (최소화) |

## 베테랑 점검 포인트

### 1. LCO 비중 12%+ 케이스
- 세탄·CFPP·안정성 모두 동시 검토
- WAFI 응답이 평소보다 낮으면 LCO 영향 1순위 의심
- `blend_component` reason code 필수 추가

### 2. FCC 운전 변경 직후
- LCO 성상이 며칠 단위로 흔들릴 수 있음
- 첫 3 배치는 면밀히 모니터링

### 3. HDS LCO Hydrotreater 부진 시
- 일부 정유사는 LCO 전용 HDS 운영
- 부진 시 황·올레핀 잔류 → 디젤 안정성 영향

### 4. 색상 검사 미달
- LCO 비중 高 + 장기 저장 → 색상 변색 위험
- 색상 검사값 추세 모니터링
