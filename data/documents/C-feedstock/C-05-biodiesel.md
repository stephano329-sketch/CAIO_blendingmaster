# C-05. Biodiesel (BD100) — 의무 혼합 반제품

## 정의와 위치

Biodiesel(바이오디젤, 통칭 BD100 또는 FAME)은 **식물성 기름이나 동물성 지방을 메탄올과 에스테르화 반응**시켜 얻은 신재생 디젤 연료다. 한국에서는 「신재생에너지 연료혼합 의무제도」에 따라 자동차용 경유에 의무적으로 혼합한다.

## 화학 구조

BD100은 **FAME (Fatty Acid Methyl Ester, 지방산 메틸 에스테르)** 의 혼합물이다. 주 구성 분자:

```
R-COO-CH₃   (R = C13~C17 사슬, 일부 이중결합 포함)
```

대표 FAME 종:
- 메틸 팔미트산 (C16:0)
- 메틸 스테아르산 (C18:0)
- 메틸 올레산 (C18:1) — 대두유, 유채유에서 多
- 메틸 리놀레산 (C18:2) — 대두유에서 多

## 주요 성상

| 항목 | 일반 범위 | 평균 |
| --- | --- | --- |
| 밀도 (15°C) | 870~890 kg/m³ | 880 kg/m³ |
| 황분 | < 2 ppm | < 1 ppm |
| 세탄 수 | 47~55 | 50 |
| **CFPP (BD100 단독)** | **-3 ~ +12°C** | **+5°C** |
| 인화점 | > 130°C | 165°C |
| 동점도 (40°C) | 3.5~5.0 mm²/s | 4.5 |
| 산가 (Acid Value) | < 0.5 mg KOH/g | 0.3 |
| 산화 안정성 (Rancimat) | > 6 hr | 8 hr |
| n-파라핀 (디젤 풀 기준) | 0% | 0% |
| 방향족 | 0% | 0% |

## 디젤 풀에 미치는 영향

### CFPP 영향
Bio 3% × +5°C = **+0.15°C**의 baseline CFPP 부담. 작아 보이지만 혹한기 빡빡한 마진에서는 의식 가능한 수준.

### 세탄 영향
BD100 세탄 50+이므로 디젤 풀 세탄에 **약간 긍정적**. 다만 디젤 평균 세탄이 52이므로 큰 변동 없음.

### 윤활성 영향
BD100은 **윤활성이 우수**하여 ULSD의 윤활성 부족을 자연스럽게 보완. HFRR 검사 시 도움.

### 산화 안정성 영향
BD100 자체는 산화 안정성 상품이지만 **장기 저장 시 산화 위험**:
- 빛, 산소, 금속 노출 시 산화 가속
- 산화물이 슬러지 형성 → 필터 막힘 가능
- 디젤 풀 전체의 산화 안정성 저하

### 흡습성
BD100은 약간 **수분 흡수**한다:
- 수분 → 가수분해 → 산가 상승
- 미생물(특히 박테리아·곰팡이) 생장 가능성
- 정기적 수분 함량 검사 필요

## 운영 가이드

### 1. BD100 신규 lot 도입
- 첫 1주 산화 안정성·CFPP 영향 면밀 모니터링
- 원료(대두 vs 폐식용유 등)에 따라 성상 미세 차이

### 2. 장기 저장 BD3 제품
- BD3 형태로 30일 이상 저장 시 산화 안정성 재검사 권장
- 출하 직전 샘플 색상·산가 확인

### 3. 혹한기 마진 빡빡한 케이스
- Bio +0.15°C 부담을 의식하고 WAFI ppm 계산
- 마진 1°C 이내 케이스는 신중

### 4. 고무 호환성
일부 구형 고무 호스·오링은 BD3에서 부풀거나 균열 가능. 차량 오너 매뉴얼 확인.

## 베테랑 점검 포인트

1. **BD100 lot 변경 시점 추적**: lot마다 미세 성상 변동 가능
2. **장기 저장 BD3 색상 모니터링**: 색상 변화는 산화 신호
3. **수분 함량 정기 검사**: 0.05% 초과 시 주의
4. **해외 수출용 디젤**: 일부 시장은 BD 함량 제한 → 별도 풀 운영
