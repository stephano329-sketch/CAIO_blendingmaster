# C-07. 계절별 반제품 권장 비율

## 개요

본 문서는 동절기(winter, CFPP -16°C 목표)와 혹한기(deep_winter, CFPP -23°C 목표) 각 시즌에서 권장되는 반제품 비율 가이드를 제공한다. 본 시스템의 `target_cfpp` 변수와 함께 사용하여 다양한 등급의 디젤을 시연 가능.

## 동절기 (winter) — CFPP 목표 -10 ~ -16°C

### 보수형 (안전 마진 우선)
```
LGO 65~75% + HGO 5~15% + LCO 5~8% + Kero 0~3% + Bio 3% + WAFI Type A 200~250ppm
```
- 마진 4°C 이상 안정 확보
- WAFI 비용은 다소 높지만 재블렌딩 위험 최소화
- 권장 시나리오: 신규 슬레이트 도입 직후, 탱크 변경 직후

### 균형형 (비용·안전 절충)
```
LGO 60~70% + HGO 10~20% + LCO 7~10% + Kero 0~2% + Bio 3% + WAFI Type A 150~200ppm
```
- 마진 2~3°C 확보
- 일반적인 동절기 운영 패턴
- 권장 시나리오: 운전 안정 시기

### 비용 우선형
```
LGO 55~65% + HGO 15~25% + LCO 10~12% + Kero 0% + Bio 3% + WAFI Type B 100~150ppm
```
- 마진 1~2°C (빡빡)
- 첨가제·반제품 비용 최소화
- 권장 시나리오: 마진 여유가 있고 검사 신뢰도 높을 때

## 혹한기 (deep_winter) — CFPP 목표 -16 ~ -23°C

### 보수형 (안전 마진 우선)
```
LGO 75~80% + HGO 0~5% + LCO 2~5% + Kero 7~10% + Bio 3% + WAFI Type C 400~500ppm
```
- 마진 3°C+ 확보
- 한계 운전이지만 안전
- 권장 시나리오: 한파 예보, 산악 지역 출하

### 균형형
```
LGO 70~78% + HGO 5~10% + LCO 5~7% + Kero 5~8% + Bio 3% + WAFI Type C 300~400ppm
```
- 마진 1~2°C
- 일반 혹한기 운영
- 권장 시나리오: 안정된 운전 + 정상 검사 신뢰도

### 한계 운전형 (목표 -23°C)
```
LGO 80~85% + HGO 0% + LCO 0~2% + Kero 8~10% + Bio 3% + WAFI Type C 450~500ppm
```
- 마진 0~1°C (매우 빡빡)
- 물리적 달성 한계 부근
- 권장 시나리오: 특수 사양 요구, 추가 점검 필수

## 시즌 전환기 (Transition)

### 동절기 → 하절기 (4월 15일 부근)
- 2주 transition 운영
- 동절기 사양 충족 + 하절기 사양 동시 충족
- 보수적 LGO 65% + HGO 15% + LCO 8% + Bio 3% + WAFI Type A 100ppm
- 4월 15일 이후 WAFI 점진 제거

### 하절기 → 동절기 (11월 16일 부근)
- 미리 1~2주 동절기 사양 준비
- WAFI 재고 가동, 운영 적응
- LGO 비중 확대, HGO 점진 축소

## 비상 시나리오

### 갑작스런 한파
- 단기 (1~3일): WAFI ppm 즉시 증액
- 중기 (1주): Kero 비중 확대
- 장기 (1개월+): HCC 운전 모드 변경 검토

### 원유 슬레이트 변경 시점
- 첫 1주: 보수형 + 검사 강화
- 2주차: 신규 베이스 CFPP 데이터 축적
- 3주차: WAFI 응답 재교정

### 첨가제 공급 차질
- 단기 (1~2일): 재고분으로 보완
- 중기 (1주): 다른 Type으로 대체 + 응답 곡선 재학습
- 장기: 다른 공급사 확보

## 권장 비율과 본 시스템 모델링의 정합

본 시스템 `synthetic_generator.py`의 LHS 샘플링 범위:

| 변수 | 범위 | 본 가이드와의 관계 |
| --- | --- | --- |
| `lgo_ratio` | [0.40, 0.85] | 모든 권장 시나리오 포함 |
| `hgo_ratio` | [0.00, 0.30] | 모든 시나리오 포함 |
| `lco_ratio` | [0.00, 0.20] | 모든 시나리오 포함, 위험 조합 (12%+) 일부 포함 |
| `kero_ratio` | [0.00, 0.10] | 모든 시나리오 포함 |
| `biodiesel_ratio` | 0.03 (고정) | KS 의무 |

## 베테랑 점검 포인트

각 시나리오에서 베테랑이 마지막에 재확인하는 항목:

1. **마진 충분 여부** (1순위)
2. **검사 신뢰도** (재현성, 추세 일관성)
3. **탱크 이력** (잔류 영향)
4. **첨가제 균질도** (충분한 교반 시간)
5. **다음 배치 영향** (현재 결정이 다음 배치에 미칠 영향)
