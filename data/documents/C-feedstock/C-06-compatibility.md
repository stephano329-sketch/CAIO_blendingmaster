# C-06. 반제품 호환성 매트릭스

## 개요

여러 반제품을 동시에 블렌딩할 때, 각 조합은 단순히 가중평균이 아닌 **상호작용**을 일으킨다. 본 문서는 자주 마주치는 위험 조합과 권장 조합을 정리한다.

## 위험 조합 (주의 필요)

### 1. LCO 高 + WAFI Type B (저ppm 효율형)

- **상황**: LCO 비중 12%+ 인데 WAFI 100~150ppm Type B만 사용
- **위험**: LCO 방향족이 Type B 응답을 감쇠 → 실제 ΔCFPP가 예상보다 30~40% 낮음
- **결과**: CFPP 미달 위험
- **대응**:
  - LCO 비중 축소
  - WAFI Type C (고ppm 잠재력형)으로 변경
  - WAFI ppm 1.4배 이상 증액

### 2. HGO 高 + Kero 동시 高

- **상황**: HGO 25% + Kero 10% (양 극단의 분획 동시 사용)
- **위험**:
  - 디젤 풀 비점 분포가 양 극단으로 갈라짐 → 증류성상 T90 사양 문제
  - 인화점 ~점도 동시 위협
- **결과**: 다중 사양 미달 가능
- **대응**: 일반 운영에서 권장하지 않음. 비상 시에만.

### 3. CDU 직접 HGO 만 + LCO

- **상황**: HCC 셧다운으로 CDU HGO만 사용 + LCO 10%
- **위험**:
  - CDU HGO 세탄 45 + LCO 세탄 30 → 풀 세탄 50 미만 위험
  - 두 반제품 모두 무거움 → 밀도 상한 위협
- **대응**: LCO 비중 축소 + 세탄 향상제 추가

### 4. 새 BD100 lot + 장기 저장

- **상황**: 신규 BD100 도입 후 BD3 형태로 30일+ 저장
- **위험**: 산화 안정성 미달 → 색상 변색·슬러지
- **대응**: 출하 전 색상·산가·Rancimat 재검사

### 5. 탱크 변경 직후 + 혹한기 빡빡한 마진

- **상황**: 직전 다른 제품 저장한 탱크 → 세정 후 첫 사용 + 혹한기 -23°C 목표
- **위험**: 잔류 영향 ±1~2°C 변동
- **대응**: 안전 마진 +50ppm WAFI 추가, 첫 1배치는 면밀 모니터링

## 권장 조합 (안전·경제적)

### 1. 동절기 표준
```
LGO 65% + HGO 15% + LCO 7% + Kero 0% + Bio 3% + WAFI Type A 200ppm
→ 예상 CFPP -14°C 수준
```

### 2. 혹한기 표준
```
LGO 75% + HGO 5% + LCO 5% + Kero 7% + Bio 3% + WAFI Type C 350ppm
→ 예상 CFPP -20°C 수준
```

### 3. 혹한기 한계 운전 (-23°C 목표)
```
LGO 80% + HGO 0% + LCO 2% + Kero 10% + Bio 3% + WAFI Type C 500ppm
→ 예상 CFPP -22 ~ -25°C
```

### 4. 비용 우선 (마진 풍부 케이스)
```
LGO 55% + HGO 25% + LCO 10% + Kero 0% + Bio 3% + WAFI Type B 100ppm
→ 예상 CFPP -10 ~ -8°C, 마진 풍부 시 적합
```

## 호환성 매트릭스 요약

| 조합 | 점수 | 주의사항 |
| --- | --- | --- |
| LGO + HGO 적정 | ★★★★★ | 표준 |
| LGO + Kero | ★★★★☆ | 인화점 확인 |
| LGO + LCO 5~8% | ★★★☆☆ | LCO 영향 인지 |
| LGO + LCO 12%+ | ★★☆☆☆ | WAFI 강화 필수 |
| HGO + LCO | ★★☆☆☆ | 세탄·밀도 동시 위협 |
| HGO + Kero | ★☆☆☆☆ | 비점 분포 갈라짐 |
| LCO + Kero | ★★★☆☆ | 가능, 흔하지 않음 |
| 모든 반제품 + Bio 3% | ★★★★★ | 의무, 큰 영향 없음 |

## 베테랑 점검 포인트

1. **LCO 비중과 WAFI Type 매칭** 1순위 확인
2. **다중 검사 항목 동시 미달 가능성** 사전 검토
3. **신규 조합** (예: 신규 슬레이트 + 새 첨가제) 첫 1주 면밀 모니터링
4. **호환성 외에도 비용 균형** 항상 고려
