# B-02. 한국 자동차용 경유 규격 (KS M 2610)

## 규격 개요

KS M 2610은 한국에서 판매되는 자동차용 경유의 품질 사양을 정한 표준이다. 산업통상자원부 고시 "석유제품의 품질기준 및 검사방법"과 함께 적용된다.

## 주요 사양 항목

| 항목 | 단위 | 기준 | 측정법 |
| --- | --- | --- | --- |
| 황분 | mg/kg (ppm) | ≤ 10 | KS M ISO 20846 / ASTM D5453 |
| 세탄 지수 | — | ≥ 52 | KS M ISO 4264 / ASTM D4737 |
| 세탄 수 | — | ≥ 52 | KS M ISO 5165 / ASTM D613 |
| 인화점 | °C | ≥ 40 | KS M ISO 2719 / ASTM D93 |
| 동점도 (40°C) | mm²/s | 1.9~5.5 | KS M ISO 3104 / ASTM D445 |
| 밀도 (15°C) | kg/m³ | 815~835 (일반) | KS M ISO 12185 / ASTM D4052 |
| 증류성상 T90 | °C | ≤ 360 | KS M ISO 3405 / ASTM D86 |
| 색상 | — | ≤ 2.5 | KS M ISO 2049 / ASTM D1500 |
| 윤활성 (HFRR) | μm | ≤ 460 | ASTM D6079 |
| 잔류탄소 (10% 잔류분) | wt% | ≤ 0.30 | KS M ISO 10370 |

## 저온유동성 사양 (계절·지역별)

자동차용 경유의 핵심 차별 사양은 **CFPP (Cold Filter Plugging Point, 한외여과점)**이며, 계절과 지역에 따라 다음과 같이 구분된다:

| 적용 시기 | 적용 지역 | CFPP 기준 |
| --- | --- | --- |
| **하절기** (4월 16일 ~ 11월 15일) | 전국 | ≤ -5°C |
| **동절기** (11월 16일 ~ 4월 15일) | 일반 지역 | ≤ -16°C |
| **혹한기** (12월 ~ 2월) | 강원·충북 일부 산악 | ≤ -23°C (특별 규격) |

> 주: 정확한 적용 일자와 지역은 매년 산업통상자원부 고시로 확정된다. 본 시스템에서는 단순화하여 winter(-16°C) / deep_winter(-23°C) 두 가지로 모델링한다.

## 고객별 추가 사양

표준 KS M 2610을 충족하는 것 외에, 일부 OEM·고객사는 추가 사양을 요구한다:

- **유럽 EN 590 호환**: 일부 수출용 디젤
- **고급 휘발성 표준 (Premium)**: CFPP 더 낮은 값, 세탄 더 높은 값
- **건설장비용**: 인화점 더 높은 값

본 시스템에서는 `target_cfpp`를 사용자 입력으로 받아 다양한 등급에 대응한다.

## 바이오디젤 의무 혼합

「신재생에너지 연료혼합 의무제도(RFS)」에 따라 자동차용 경유는 일정 비율의 바이오디젤을 의무 혼합한다:

| 연도 | 의무 비율 |
| --- | --- |
| 2018 | 3.0% |
| 2021 | 3.5% (한시적) |
| **2026 (현재)** | **3.0% (재조정)** |
| 2030 (목표) | 5.0% |

본 시스템은 `biodiesel_ratio = 0.03`으로 고정.
