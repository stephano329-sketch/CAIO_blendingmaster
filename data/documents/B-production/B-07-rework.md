# B-07. 재블렌딩(Rework) 절차

## Rework가 필요한 상황

검사 결과가 KS M 2610 또는 고객 사양을 만족하지 못하는 경우, 두 가지 경로가 있다:

1. **첨가제 보정**: WAFI 추가 투입으로 미세 조정
2. **재블렌딩**: 반제품 비율 조정으로 본격 보정

문제의 심각성과 사양 항목에 따라 결정된다.

## 첨가제 보정 (소규모 보정)

### 적용 조건
- 단일 항목 미달 (CFPP만, 또는 세탄만)
- 미달 폭이 작음 (CFPP 1~3°C)
- 첨가제만으로 대응 가능한 항목

### 절차
```
1. 미달 정도 측정
2. 응답 곡선으로 추가 ppm 계산
3. 안전 마진 추가 투입
4. 30분 정치 + 교반
5. 재검사
```

### 예시
- CFPP 측정 -14°C, 목표 -16°C → 부족 2°C
- 현재 WAFI 200ppm Type A → +50~100ppm 추가
- 재검사 후 -16.5°C 확인 → 출하

## 재블렌딩 (대규모 보정)

### 적용 조건
- 여러 항목 동시 미달
- 단일 항목이라도 미달 폭이 큼 (CFPP 5°C+, 세탄 3+)
- 첨가제만으로 대응 불가 (예: 밀도, 색상, 황 등)
- 검사값 신뢰도 의심으로 시료 자체에 의문

### 절차
```
1. 문제 진단: 어느 반제품·첨가제·공정이 원인인가
2. 보정 비율 계산 (시뮬레이터 또는 베테랑 경험)
3. 추가 반제품 투입 또는 일부 분량 다른 풀로 이송
4. 충분한 교반 + 정치
5. 1차 재검사 → 보정 → 종합 검사
6. 출하
```

### 자주 발생하는 재블렌딩 시나리오

#### 시나리오 1: CFPP 큰 미달
- 진단: HGO 비중 高 또는 LCO 高
- 보정: LGO 추가 또는 Kero 투입 + WAFI 강화
- 비용: WAFI 단독 보정의 5~10배

#### 시나리오 2: 황 함량 초과
- 진단: HDS 운전 부진 또는 시료 오염
- 보정: 저황 LGO 추가 투입으로 희석
- 비용: 저황 LGO 자체가 고가

#### 시나리오 3: 세탄 미달
- 진단: LCO 비중 高
- 보정: LCO 일부 제거 + 세탄 향상제 투입
- 비용: 화학 비용 + 시간

## 비용 영향

PRD §03 "동절기 재블렌딩 250건/년 × 회당 4천만원 = 약 100억원" 가정에서:
- **회당 4천만원**: 추가 첨가제 + 추가 반제품 + 인건비 + 시간 손실
- **연 250건**: 동절기·혹한기 5개월 × 평균 50건/월 = 250건
- **AI 도입 시 효과**: 30~40% 감소 가능 (175건/년 이하 목표)

## 재블렌딩 vs Downgrade

심각한 미달 시 재블렌딩이 경제적이지 않은 경우, **다른 제품으로 격하(Downgrade)**:
- ULSD → 비도로용 디젤 (off-road, 사양 완화)
- ULSD → 원료유 (Hydrocracker 원료로 재투입)

격하는 가격 손실을 동반하므로 최후의 수단.

## 베테랑 의사결정 패턴

베테랑은 미달 발견 시 다음 순서로 사고:

1. **재검사부터**: 측정 오류 가능성 0순위 점검
2. **첨가제 보정 가능 여부**: 단순한 단일 항목이면 시도
3. **재블렌딩 견적**: 비용·시간 추정
4. **격하 검토**: 재블렌딩 무의미하면 격하
5. **사후 분석**: 동일 문제 재발 방지를 위한 원인 기록
