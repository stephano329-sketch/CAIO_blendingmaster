# B-03. 계절별 디젤 생산 전략

## 계절 구분과 CFPP 목표

한국 자동차용 경유는 KS M 2610과 산업부 고시에 따라 계절별로 CFPP 목표가 달라진다. 정유사는 이에 맞춰 반제품 비율과 첨가제 운영을 조정한다.

| 계절 | 기간 (일반) | CFPP 목표 | 본 시스템 코드 |
| --- | --- | --- | --- |
| 하절기 | 4월 16일 ~ 11월 15일 | ≤ -5°C | (MVP 범위 외) |
| 동절기 | 11월 16일 ~ 4월 15일 | ≤ -16°C | `winter` |
| 혹한기 | 12월 ~ 2월 (산악 일부) | ≤ -23°C | `deep_winter` |

## 동절기 (winter) 전략

### 반제품 비율
- LGO 비중 확대: 60~75% (하절기 50~60% 대비)
- HGO 비중 축소: 0~20% (CFPP 부담 줄임)
- LCO 제한: 5~10% (LGO 부담 보완 정도)
- Kerosene 추가: 0~5% (필요 시 CFPP 미세 조정)
- Biodiesel: 3% 의무

### WAFI 운영
- 평균 투입량: 100~300 ppm
- 일반적으로 Type A (균형형) 사용
- 주요 의사결정: "비용 우선이냐 안전 마진 우선이냐"

### 베테랑 의사결정 패턴
- LGO 단독 비중 70%+ + WAFI 200ppm: 표준
- LCO 12%+ 발견 시: WAFI 효과 30% 감쇠 가정 (LCO_DAMPING)
- 탱크 변경 직후: WAFI +50ppm 안전 마진 추가 권장

## 혹한기 (deep_winter) 전략

### 반제품 비율
- LGO 최대화: 70~85%
- Kerosene 활용: 5~10% (저온유동성 강화)
- HGO 최소화: 0~10%
- LCO 최소화: 0~5% (방향족 영향 회피)
- Biodiesel: 3% 의무 (단, 산화 안정성 더 면밀히 모니터링)

### WAFI 운영
- 평균 투입량: 250~500 ppm
- Type C (고ppm 잠재력형) 선호 — 500ppm까지 효과 지속
- 일부 정유사는 Type A + Type C 병용

### 도달 가능 한계
물리적으로 달성 가능한 CFPP 하한:
- LGO 80%, Kero 10% 블렌드 + WAFI Type C 500ppm ≈ -22 ~ -25°C
- KS M 2610 혹한기 -23°C는 거의 한계 운전
- 베테랑은 마진 1~2°C를 넘지 않으면 항상 위험으로 판단

## 환절기(전환기) 운영

11월 16일과 4월 15일은 동절기 ↔ 하절기 전환일. 이 시기에는:

1. **재고 전환**: 하절기 사양 재고 소진 + 동절기 사양 점진 도입
2. **2주 transition 기간**: 양쪽 사양 모두 충족하는 보수적 블렌딩
3. **WAFI 재고 관리**: 하절기 동안 거의 사용 안 했으므로 재고 안정성 확인 (장기 보관 분리 위험)

## 비상 상황 대응

### 갑작스런 한파
일기예보 영향 등으로 갑자기 더 차가운 사양이 필요한 경우:
- 단기: WAFI 추가 투입으로 보정
- 중기: Kero 비중 확대
- 장기: HCC 운전 모드 변경 (Maximum Distillate)

### 원유 슬레이트 변경
새 원유가 도입되면 LGO 성상이 변동:
- 첫 1주 면밀히 모니터링
- 신규 베이스 CFPP 데이터 축적
- WAFI 응답성 재교정
