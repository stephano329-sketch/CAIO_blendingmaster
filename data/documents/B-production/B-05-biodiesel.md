# B-05. 바이오디젤 의무 혼합 운영

## 제도 배경

「신재생에너지 연료혼합 의무제도(RFS, Renewable Fuel Standard)」는 2015년부터 시행되었으며, 자동차용 경유에 일정 비율의 바이오디젤(BD100)을 의무 혼합하도록 규정한다.

## 의무 혼합 비율 추이

| 연도 | 의무 비율 |
| --- | --- |
| 2015 | 2.5% |
| 2018 | 3.0% |
| 2021 (한시 상향) | 3.5% |
| **2026 (현재)** | **3.0%** |
| 2030 (목표) | 5.0% |

**본 시스템은 `biodiesel_ratio = 0.03` 고정.**

## 바이오디젤(BD100)이란?

식물성 기름(콩, 유채, 폐식용유 등)이나 동물성 지방을 메탄올과 에스테르화 반응시켜 얻은 **FAME (Fatty Acid Methyl Ester)**. 일반적으로 BD100(100%)을 정유사가 구매한 뒤 디젤에 3% 비율로 블렌딩하여 BD3 제품을 만든다.

## 바이오디젤의 디젤 품질 영향

### 긍정적 영향
- **세탄가 향상**: BD100 자체 세탄 50~52, 디젤 풀 평균 세탄 약간 끌어올림
- **윤활성 개선**: ULSD의 윤활성 부족을 일부 보완
- **유황 함량 0**: 디젤 평균 황 함량 약간 낮춤

### 부정적 영향
- **CFPP 악화**: BD100 단독 CFPP는 +0~+10°C로 디젤 평균보다 따뜻 → 동절기에 부담
- **산화 안정성 저하**: 불포화 지방산 함유 → 장기 저장 시 산화·슬러지
- **수분 함유 가능성**: 흡습성으로 미생물 생장 가능성
- **고무 호환성**: 일부 구형 고무 호스 부풀림

## 본 시스템의 모델링

`physical_model.py`에서 Bio의 baseline CFPP 기여:
- Bio 비율 = 0.03 (고정)
- Bio CFPP = +5°C
- 기여도: 0.03 × 5 = **+0.15°C** (실질적으로 매우 작음)

따라서 Bio 3% 의무 혼합은 CFPP에 약 0.15°C 정도의 부담을 준다. WAFI 운영에 큰 변수가 되지는 않지만, 마진이 빡빡한 혹한기 케이스에서는 의식할 만한 수준이다.

## 혼합 시점

BD100은 다음 두 시점 중 하나에서 디젤에 혼합된다:

### 1. 정유사 단계 혼합 (정적/동적)
- 정유공장 블렌드 탱크에서 미리 혼합
- 균질도 우수, 보관 중 변동 적음
- 단, BD3 상태로 장기 저장 시 산화 안정성 모니터링 필요

### 2. 출하 단계 혼합 (인라인)
- 출하 트럭 적재 시 인라인으로 혼합
- 신선한 상태로 출하
- 다만 균질도 검증이 어려움

한국 정유사는 1번 방식이 주류이며, 본 시스템도 이를 가정.

## 베테랑 점검 포인트

- **BD100 신규 lot 도입 후 1주**: 첫 1~2 배치는 산화 안정성·CFPP 영향 확인
- **혹한기 마진 빡빡한 케이스**: Bio 0.03의 +0.15°C 부담을 잊지 않고 계산
- **장기 저장 BD3 제품**: 출하 전 산화 안정성 재검사 권장
