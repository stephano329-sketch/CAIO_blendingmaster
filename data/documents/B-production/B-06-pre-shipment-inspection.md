# B-06. 출하 전 검사 흐름

## 검사의 단계

블렌딩 완료부터 출하까지 검사는 일반적으로 **3단계**로 진행된다.

### 1단계: 1차 품질 검사 (블렌딩 직후)

블렌딩 완료 후 30분 정치 → 시료 채취 → 핵심 항목 검사:

| 검사 항목 | 측정 시간 | 목적 |
| --- | --- | --- |
| CFPP | 30~60분 | 저온유동성 1차 확인 |
| 황분 | 5~10분 | 환경 규제 확인 |
| 밀도 | 5분 | 사양 확인 |
| 색상 | 즉시 | 정상 외관 확인 |

이 단계에서 사양 미달이면 **WAFI 추가 투입**, 또는 반제품 비율 조정 후 재블렌딩.

### 2단계: 종합 검사 (1차 통과 후)

| 검사 항목 | 측정 시간 |
| --- | --- |
| 세탄 지수 (계산) | 즉시 (계산식) |
| 세탄 수 (엔진 측정) | 1~2시간 |
| 인화점 | 30분 |
| 동점도 | 30분 |
| 증류성상 | 1시간 |
| 잔류탄소 | 2~3시간 |
| 윤활성 (HFRR) | 4시간 |

### 3단계: 출하 전 최종 확인 (출하 직전)

| 검사 항목 | 목적 |
| --- | --- |
| CFPP 재검사 | 시간 경과 후 변동 확인 |
| 색상·외관 | 저장 중 변동 확인 |
| 출하 트럭 시료 | 적재 직전 균질도 확인 |

## 검사 시료 채취 방법

KOLAS 인정 절차에 따라:

1. **충분한 정치**: 블렌딩 완료 후 최소 30분 (이상적으로는 2시간)
2. **3점 채취**: 탱크 상부·중부·하부에서 각각 채취 (자동 샘플러 권장)
3. **균질화**: 3개 시료를 1리터 용기에 합쳐 균질하게 흔들기
4. **분주**: 검사 항목별로 분주 (CFPP용·세탄용·기타)

## 검사값 신뢰도 평가

베테랑 연구원은 단순히 "통과/미통과"가 아니라 **검사값의 신뢰도** 자체를 평가한다.

### 신뢰도가 낮다고 판단되는 상황

- **재현성 부족**: 동일 시료 2회 측정 시 1°C 이상 차이
- **모순된 항목**: CFPP는 통과했는데 PP가 비정상적으로 낮음
- **장비 이상 의심**: 최근 캘리브레이션 미흡, 표준 시료 검사값 변동
- **추세 이탈**: 직전 N 배치 평균 대비 2σ 이상 벗어남

→ `inspection_reliability` reason code

### 대응 절차

1. 다른 측정 장비로 재측정
2. 새로운 시료로 재측정
3. 추가 시간 정치 후 재측정
4. 인접 검사 항목 (CFPP ↔ CP ↔ PP) 일관성 확인

## 출하 결정 기준

다음 조건을 모두 만족하면 출하:

1. ✅ 모든 KS M 2610 사양 충족
2. ✅ 검사값 신뢰도 의심 없음
3. ✅ 안전 마진 적정 (CFPP 기준 1°C 이상 권장)
4. ✅ 추세적 변동 없음 (직전 배치들과 일관)

하나라도 미흡하면 **출하 보류**, 베테랑 검토.
