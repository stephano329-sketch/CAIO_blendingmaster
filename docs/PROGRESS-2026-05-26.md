## 2. 신뢰도 공식 재설계

### `backend/services/recommend_service.py`의 `_decide()`
- 옛 공식 `0.5 + 0.1 × margin` 제거 (입력별로 거의 같은 값)
- 새 공식: 두 신호의 가중 평균
  - **신호 1 (agreement)**: top-3 유사 사례 중 최종 decision과 일치 비율
  - **신호 2 (margin_signal)**: decision별 마진 경계 거리
    - normal: 경계 3.0에서 멀수록 ↑
    - caution: 밴드 [1, 3]의 중심 2.0에서 최대
    - risk: 1.0 경계에서 더 음수일수록 ↑
- `confidence = 0.5 × agreement + 0.5 × margin_signal` (clamp 0.30~0.95)
- 검증: 0.30 ~ 0.62 등으로 입력별 분기 확인

## 11. 추가 작업 (같은 날 후속)

### 11-1. ANTHROPIC_API_KEY 트러블슈팅
- `.env`에 키 추가 후에도 LLM 미사용 폴백 발생 → 원인 분석
- `backend/main.py` 어디에서도 `load_dotenv()` 호출 안 함 발견
- 1차: `load_dotenv()` 추가 → 여전히 문제 발생 (uvicorn 다른 cwd)
- 2차: `Path(__file__).parents[1] / ".env"` 절대 경로로 `load_dotenv(dotenv_path=...)` 사용 → 해결
- LLM 호출 후 `BadRequestError` 발생 → 모델명 `claude-sonnet-4-5` → `claude-sonnet-4-6`으로 변경

### 11-2. 대시보드 테이블 정렬 + 로그 ID 간소화
- 컬럼 폭 명시 (`<colgroup>` + `<col>` per column) — 7개 컬럼 폭 고정
- 로그 ID 형식 단순화:
  - 이전: `D-260526-153012-A3F2` (timestamp + uuid suffix)
  - 변경: `D-YYMMDD-NNN` (그 날의 순번, zero-padded)
  - `_persist_decision_log()`에서 `func.count()`로 오늘 시퀀스 산출
- 짧아진 ID에 맞춰 ID 컬럼 200px → 130px로 축소, 남은 폭 결과 컬럼에 분배

### 11-3. 신뢰도 설명 헤드라인 (이후 제거)
