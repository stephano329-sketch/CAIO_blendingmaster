- `backend/routers/dashboard.py`: `POST /decision-logs` 신규

  - 오늘 시퀀스 기반 `D-YYMMDD-NNN` 자동 생성
  - 응답: `{ log_id, selected_scenario }`

### 1-3. 프론트 변경
- `frontend/lib/api.ts`: `createDecisionLog()` 메서드 추가
- `frontend/app/judge/page.tsx`: "시나리오 선택" 클릭 → POST `/decision-logs` 호출
  - 폼 요청 페이로드 + AI 응답 + 사용자 선택 시나리오 한 번에 저장
  - 받은 `log_id`를 `result.log_id`에 주입 → 이후 대시보드 실측 PATCH가 동일 로그에 적용됨
  - 채택 메시지: `... (DB 저장 완료 · D-260528-007)` 또는 실패 사유

### 1-4. 부수 효과
- "AI 상담 요청" 또는 "다시 입력"만 누르고 종료 시 DB에 흔적 없음

## 3. 제품 배합 일지 (`/journal`) 신규

### 3-1. 사이드바
"AI 상담" 바로 아래에 "제품 배합 일지" 메뉴 추가, 구분선이 이 메뉴 아래로 이동.

```
대시보드
신규 판단
AI 상담
제품 배합 일지   ← 신규
─────
지식 추출
경험치 DB
RAG 문서 확인
```

### 3-2. 백엔드 (`backend/routers/dashboard.py`)
`GET /journal/batches?limit=&offset=` — DecisionLog 전체 행을 카드용 형태로 가공:
- 기본: `log_id`, `created_at`, `season`, `blend_components`, `target_cfpp`
- AI 추천: `predicted_cfpp_baseline`, `selected_scenario`, 선택 시나리오의 WAFI ppm/타입/예측 CFPP/마진
- 후속: `check_priority`, `similar_case_ids`
- 실측: `actual_cfpp`, `actual_wafi`

### 3-3. 프론트 (`frontend/app/journal/page.tsx`)
경험치 DB 카드 스타일 재사용:
- 상단 stat 3개: 총 일지 / 실측 입력 완료 / 시나리오 채택 완료
- 검색 바 (로그 ID, 계절, 시나리오 라벨)
- 카드 구조:
  - 헤더: log_id + 계절 + 시나리오 칩 + 작성 일시
  - **블렌딩**: LGO/HGO/LCO/Kero/Bio 분율
  - **CFPP · WAFI**: 목표 / 베이스라인 / WAFI 후 예측 / WAFI ppm/타입 / 마진
  - **실측**: `CFPP 실측값 (예측차이 +0.3°C)`, `WAFI 실투입 (예측차이 +0 ppm)`
  - **유사 사례**: case_id 태그 (호버 시 표 툴팁)

### 3-4. 페이지네이션
- 페이지당 **10건**
- 11건 이상이면 `← 이전 / 현재페이지 / 다음 →` 표시
- 검색 변경 시 1페이지로 자동 리셋

### 3-5. 시나리오 칩 색상 차등
| 시나리오 | 배경 | 글자 | 테두리 |
|---|---|---|---|
| 비용 최소 | 연한 파랑 | 진한 파랑 | 파랑 |
| 균형 | 연한 주황 | 진한 주황 | 주황 |
| 안전 우선 | 연한 초록 | 진한 초록 | 초록 |

### 3-6. 유사 사례 호버 툴팁
신규 판단의 툴팁과 동일한 가로형 표:
- 블렌딩 구성 (%): LGO/HGO/LCO/Kero/Bio
- CFPP · WAFI · 컨텍스트
- 캐싱: 한 번 fetch한 case는 `caseCache`에 저장
- viewport 클램핑 (`position: fixed`)

## 4. 유사 사례 검색 민감도 개선 (Hybrid Retrieval)

### 4-1. 문제
이전 RAG-only 검색은 한국어 자연어 임베딩에 숫자 차이가 잘 반영되지 않아, 입력값을 미세하게 바꿔도 같은 케이스 셋이 자주 반환됨.

### 4-2. 새 파이프라인 — `_retrieve_similar_cases()` in `recommend_service.py`
```
RAG 벡터 검색 (top-K 후보, 넓은 recall)
    ↓
구조적 거리 재정렬 (블렌딩 + 주요 성상 + target CFPP)
    ↓
최종 top-3 + 유사도 = 70% 구조적 + 30% RAG
```

### 4-3. 가중 스케일 (`_STRUCT_SCALES`)
스케일이 작을수록 더 민감하게 반응:
- LCO 비율 0.05 · n-파라핀 C21+ 0.8 · Biodiesel 0.02 (가장 민감)
- LGO/HGO/Kero 0.08~0.10 · n-파라핀 C16-C20 1.5
- 방향족/세탄/CFPP 3.0 · 밀도 5.0 (덜 민감)

### 4-4. 파라미터
- `CANDIDATE_K = 20` (RAG 후보 풀)
- `FINAL_K = 3` (최종 반환)
- 70/30 가중 (구조적/RAG)

### 4-5. 검증
LCO 10% / 25% / 35% (+ C21+ 차등)에서 명확히 다른 케이스 셋 반환:
- LCO 10% → D-030, D-019, D-033 (0.53, 0.52, 0.50)
- LCO 25% → D-027, D-020, D-019 (0.51, 0.48, 0.47)
- LCO 35% → D-027, D-020, D-029 (0.43, 0.41, 0.41)

## 5. AI 상담 Batch 선택 드롭다운

### 5-1. 변경 사항
- `Ctx` 타입에서 `decision` 필드 제거 (UI 미사용)
- sessionStorage 직접 의존 제거 → DB의 `/journal/batches`에서 fetch
- 페이지 마운트 시 batches 목록 fetch (limit 50)
- 기본 선택: 가장 최근 batch (응답 `created_at DESC`)
- /judge 핸드오프: sessionStorage에 batchId가 들어 있으면 그 batch를 우선 선택

### 5-2. UI
- 드롭다운: `D-260528-007 · 5/28 14:32 · 혹한기` 형식
- `(컨텍스트 없음)` 옵션 — 컨텍스트 없이 일반 상담 가능
- 선택 변경 시 ctx 자동 재계산 → LGO/HGO/.../베이스라인 상세 갱신
- `api.consult({ season })`도 선택된 batch의 계절 전달

### 5-3. 빈 상태
DB에 batch 없으면: "저장된 배합 일지가 없습니다 — 신규 판단에서 시나리오를 선택하면 여기에 표시됩니다"

## 6. 대시보드 예측 CFPP 의미 정정

이전: `pred_cfpp = predicted_cfpp_baseline` (WAFI 0 ppm 베이스라인)
변경: `pred_cfpp = (chosen scenario).predicted_cfpp` (WAFI 투입 후 예측)

`backend/routers/dashboard.py`의 `recent_logs`에서:
```python
pred_cfpp=float((chosen or {}).get("predicted_cfpp", rec.get("predicted_cfpp_baseline", 0.0))),
```
시나리오가 없는 예외 케이스에만 베이스라인으로 폴백.

## 7. 입력 UI 정돈

### 7-1. 신규 판단 입력 화면
- "최적화 우선순위" select **제거** (내부 기본값 `balanced`로 고정 송신)
- 탱크 이력 옵션 한글화: "잔류물 없음", "최근 전환", "혼합물 잔류"
- 블렌딩 구성 / 판단 조건 / 주요 성상 섹션 헤더 우측에 PoC placeholder 버튼 추가:
  - 📋 제품 배합 계획 불러오기
  - 📅 제품 운영 계획 불러오기
  - 📥 RTDB 분석값 불러오기
  - 모두 마우스 오버 시 "PoC에서 구현하지 않음" 툴팁

### 7-2. 신규 판단 결과 화면
- "위험/주의/정상 판단" 카드 제거
- 시나리오 카드:
  - 클릭으로 선택 가능, 선택된 카드에 초록 "✓ 선택됨" 배지
  - rationale 텍스트 접두사 제거 (카드 제목과 중복)
  - 목표 달성/미달성 인디케이터 (마진 ≥ 0 기준)
- "균형 시나리오 채택" → "시나리오 선택" 버튼
- 채택 메시지 → 버튼 줄 아래 별도 초록 배너
- 유사 사례 카드: case_id 점선 밑줄 + 호버 시 가로형 표 툴팁

### 7-3. 지식 추출
- 블렌딩 구성: `comp-grid`의 컬럼 수를 항목 수에 맞춰 동적 설정 → 한 줄 표시

### 7-4. AI 상담
- 응답을 `react-markdown` + `remark-gfm`으로 렌더링
- `.md` 스코프 마크다운 스타일 (`globals.css`)
