## 3. 입력 UX 개선 (judge 페이지)

세부 조정 이력:

1. **숫자 input 스피너 노출** — globals.css의 spinner 숨김 규칙 제거. 모든 number input에 위/아래 화살표 표시
2. **step 단위 설정**
   - 블렌딩 5개 항목: `step={1}` (1%씩)
   - CP, PP: `step={1}` (1°C씩)
   - 밀도: `step={0.001}` (0.001 g/cm³씩)
3. **음수 입력 버그 수정** — `parseFloat("-")` → NaN → 0으로 덮어쓰여 음수 입력 불가했던 문제 해결. 폼 상태를 number → string으로 변경, 중간 상태(`"-"`, `""`)를 그대로 유지
4. **블렌딩/밀도 음수 차단** — CP, PP, 목표 CFPP는 음수 허용, 블렌딩 5개 항목 + 밀도는 `min={0}` + 키 입력에서 `-` 시작 거부

다음 파일은 백엔드 연동 시 재사용 가능하도록 삭제하지 않고 남겨둠:
